# 小王子 · Magic Book 章节规划

> 原著：Antoine de Saint-Exupéry《Le Petit Prince》（1943），共 27 章
> 形式：Magic Book（魔法书）——让"看不见的东西"显形
> 定位：**4–8 岁，亲子共读**（大人读出哲理，孩子玩出魔法）；Level 1 短版给更小的孩子
> 语言：中 / 英 / **法**（原著是法语，名句可以听原文）

## 0. 前提

### 版权与商标（作品集原型阶段可做；商用前必须处理）
- 著作权：中国已公版（作者去世后 50 年）；欧洲大部分 2015 年公版；**法国约 2033 年、美国 2039 年**才公版。
- 商标：书名 *Le Petit Prince* 以及小王子、狐狸、玫瑰、星球等角色在多国**分别注册了商标**，遗产机构积极维权、在大中华区做品牌授权。
- 所以：**文字从法语原文自己改写**（现有中译本、英译本都有译者版权）；**画风完全自己设计**，不临摹原插画；商用前评估书名和角色授权。

### 默认决定（用户未另行指定，按建议执行，可改）
- 年龄：4–8 岁亲子共读
- 结尾：保留原著的模糊——"他回到了自己的星星上"；落在"会笑的星星"，不回避离别，但温柔
- 删去：酒鬼星球（第 12 章，不适合儿童）
- 蛇：只保留"它能把人送到很远的地方"这种原著的隐喻说法，不出现咬人的画面

### 全书的魔法铁律
每一个魔法都必须让**这一页的文字**更被理解、更被记住。和文字无关的魔法，再好玩也不放（Takacs 等 2015 元分析：一致的多媒体助理解，无关的热点伤害理解）。

## 1. 贯穿全系列的三条"长线魔法"

这三条让 10 个章节成为一个整体，也是 Magic Book「认得你 / 连着真实世界」最有力的体现：

| 长线 | 怎么运作 | 出现在 |
|---|---|---|
| **你的羊** | 第 2 章孩子亲手画的羊，住进箱子里；之后每一章都会出现（在星球上吃草、担心它吃玫瑰）。每个孩子的羊都不一样 | 2 → 3、4、10 |
| **驯服狐狸** | 狐狸说"每天同一时间来"。孩子**真实地每天来读**，狐狸就一天比一天靠近、愿意被摸；中断了它会后退一点。驯服需要好几天 | 8（并在之后每次打开书时问候你） |
| **你的星星** | 最后一章孩子选一颗星星；以后在图书馆的夜空里，那颗星星会笑（铃铛声）。晚上读，提醒孩子抬头看真的星空 | 10 → 图书馆穹顶 |

## 2. 十个章节

每章 = 一本小魔法书（4–6 个跨页，约 5–8 分钟），可单独读完。

### 第 1 章 · 第一号画 / Drawing Number One
- **原著**：第 1 章
- **这一章的核心**：大人只看见帽子，孩子看见吞了大象的蛇——**别急着下判断**
- **主魔法**：藏秘密 + 延迟判断
  - 先让孩子看那幅"帽子"，问：你看到了什么？（不给答案，等孩子说）
  - 再用魔杖的光照进去，蛇肚子里的大象显形
  - 第二号画：蛇的剖面，可以掀开看里面
  - "大人们总需要解释"——孩子可以给大人"解释"一遍（录下自己的声音）
- **跨页**：4（我六岁时的画 → 大人们说是帽子 → 透视出大象 → 我长大当了飞行员）
- **学习点**：hat / snake / elephant · chapeau / serpent / éléphant；观察与推理
- **为什么先做它**：短、完整、魔法单一而清楚；就是 Thinking Machine 的宣言

### 第 2 章 · 请给我画一只羊 / Draw Me a Sheep
- **原著**：第 2–3 章
- **核心**：想象力能装下任何东西——箱子里的羊，就是你想要的那只
- **主魔法**：**你来创造**（长线魔法"你的羊"的起点）
  - 沙漠、坠毁的飞机，一个小人儿出现："S'il vous plaît… dessine-moi un mouton!"
  - 飞行员画了三只羊，都被小王子拒绝（病了 / 是公羊有角 / 太老）——孩子可以帮着判断
  - 最后画了个有洞的箱子："你要的羊就在里面"
  - **孩子在箱子里画自己的羊**（手指画），羊就活了，在箱子里睡觉、探头
- **跨页**：5
- **学习点**：sheep / box / draw · mouton / boîte / dessiner；"Please" 礼貌用语
- **注意**：画画要极简（3 岁也能画一团云当羊），画什么都算对

### 第 3 章 · 小小的星球 / A Tiny Planet
- **原著**：第 4–6 章
- **核心**：照顾好自己的小星球——每天的小习惯很重要
- **主魔法**：会回应 + 连着真实世界
  - B612 只有一座房子那么大：**转动星球**，一圈走完
  - **拔猴面包树**：小芽要每天拔，长大了会把星球撑破（真实每天来拔一次 = 习惯）
  - **清理火山**：两座活火山、一座死火山，用小刷子扫一扫
  - **44 次日落**：挪动椅子（拖着沿星球走），就能再看一次日落——"一个人很难过的时候，就会喜欢看日落"
- **跨页**：5
- **学习点**：planet / tree / sunset · planète / arbre / coucher de soleil；数数（44）；为什么移动就能看到日落（地球自转的直观科普）
- **你的羊**：在星球上吃草——小王子担心它会吃掉猴面包树（好事）还是玫瑰（坏事）

### 第 4 章 · 玫瑰 / The Rose
- **原著**：第 7–9 章
- **核心**：爱一个人，要看她做了什么，不只是听她说了什么
- **主魔法**：会回应 + 情绪
  - 一颗种子长出花苞，迟迟不开——**孩子轻点、等待**，花一层层打开（不能催）
  - 玫瑰要玻璃罩、要屏风挡风、炫耀自己的四根刺
  - **为她罩上玻璃罩**（扣下的纸机关）、**挡风**（拉开屏风）
  - 离开那天，她终于说："我是爱你的"
- **跨页**：5
- **学习点**：rose / thorn / wind · rose / épine / vent
- **你的羊**：第 7 章的大问题——"羊会吃有刺的花吗？"飞行员答应给羊画一个嘴套（为第 10 章埋伏笔）

### 第 5 章 · 星球之旅（上）：国王和爱虚荣的人 / The King and the Vain Man
- **原著**：第 10–11 章
- **核心**：大人们的奇怪
- **主魔法**：会回应（角色有"脾气"）
  - **国王**：他命令的都是"本来就会发生的事"——孩子试着命令太阳落山，国王说"要等到合适的时候"（看钟：今天日落的真实时间！）
  - **爱虚荣的人**：孩子拍手，他就脱帽鞠躬；一直拍他一直鞠——孩子会自己发现"这有什么意思呢？"
- **跨页**：4
- **学习点**：king / clap / hat · roi / applaudir / chapeau

### 第 6 章 · 星球之旅（下）：商人、点灯人、地理学家 / Stars, Lamps and Maps
- **原著**：第 13–15 章（跳过第 12 章酒鬼）
- **核心**：拥有和照顾，有什么不同
- **主魔法**：会回应 + 数数
  - **商人**数星星，说星星都是他的——孩子帮他数，数到哪儿乱掉了（"拥有星星有什么用？"）
  - **点灯人**：他的星球一分钟转一圈，**孩子帮他点灯、熄灯**，越来越快——他是唯一不可笑的大人，因为他在照顾别的东西
  - **地理学家**：从不出门，只写不会变的东西；"玫瑰是短暂的"——小王子第一次后悔离开她
- **跨页**：5
- **学习点**：star / lamp / map · étoile / lampe / carte；数数到 20

### 第 7 章 · 地球：回声和五千朵玫瑰 / Echo and Five Thousand Roses
- **原著**：第 16–20 章
- **核心**：孤独，以及"你的那一朵"为什么不一样
- **主魔法**：**你会施魔法（语音）**
  - 沙漠里的一朵小花："人？他们没有根"
  - 爬上高山，**孩子对着山大声喊**："Bonjour!" / "你好！"——山把孩子自己的声音传回来（回声 = 用麦克风录下来、加回声再放）
  - 一座开满五千朵玫瑰的花园，小王子哭了：他以为他的玫瑰是世界上唯一的
- **跨页**：5
- **学习点**：hello / friend / alone · bonjour / ami / seul；回声的科普（声音碰到山会弹回来）
- **蛇**：第 17 章只保留一句"我能把你送到比任何船都远的地方"，画面是金色的蛇环，不吓人

### 第 8 章 · 狐狸 / The Fox　★全系列的心脏
- **原著**：第 21 章
- **核心**：驯服 = 建立联系；"真正重要的东西，用眼睛是看不见的"
- **主魔法**：**认得你（长线魔法"驯服狐狸"）+ 隐形墨水**
  - 狐狸说："请驯服我。" 怎么驯服？"每天同一时间来，坐得离我远一点，一天比一天近一点"
  - **真实的多天互动**：第 1 天狐狸远远躲在麦田里；孩子每天来，它就坐近一点；第 4–5 天可以摸它
  - 麦田是金色的——"你的头发是金色的，以后看到麦田我就会想起你"（**孩子可以选自己的头发颜色**，麦田随之变色）
  - 告别时狐狸送出秘密：这句话**一开始是隐形的**，要用魔杖（"用心"）照亮才显出来：
    *On ne voit bien qu'avec le cœur. L'essentiel est invisible pour les yeux.*
  - "你为你的玫瑰花费的时间，让她变得那么重要"
- **跨页**：6
- **学习点**：fox / friend / heart · renard / apprivoiser / cœur
- **设计重点**：这是"Magic Book 能做、纸书和视频都做不到"的最好证明——驯服必须真的花时间

### 第 9 章 · 井 / The Well
- **原著**：第 22–25 章
- **核心**：沙漠之所以美，是因为它在某个地方藏着一口井
- **主魔法**：会回应 + 连着真实世界
  - 扳道工：火车呼啸而过，"只有孩子知道自己在找什么"——孩子可以把脸贴在火车窗上
  - 卖"解渴药丸"的商人：一周省下 53 分钟——"如果是我，我会慢慢走向一口泉水"
  - 夜里走过沙漠找井；**孩子摇动辘轳**，水桶一点点升上来，辘轳吱呀作响（原著里这口井"在唱歌"）
  - "这水像一份礼物"
- **跨页**：5
- **学习点**：water / well / thirsty · eau / puits / soif；滑轮的科普（为什么摇动能把水提上来）

### 第 10 章 · 会笑的星星 / The Laughing Stars
- **原著**：第 26–27 章
- **核心**：离别，以及记得
- **主魔法**：连着真实世界（长线魔法"你的星星"的终点）
  - 小王子要回家了，"我的身体太重，带不走"——画面是他像一棵树一样轻轻倒在沙子上，没有声音（不出现蛇咬）
  - "你看星星的时候，因为我住在其中一颗上，因为我在那颗星上笑，所以你会觉得所有的星星都在笑"
  - **孩子选一颗属于自己的星星**，点它会发出铃铛般的笑声；回到图书馆，穹顶的夜空里那颗星星会一直在
  - 结尾的问题：飞行员忘了给嘴套画皮带——**你的羊**到底有没有吃掉玫瑰？书不给答案，留给孩子想（这一问是原著最美的结尾，也是延迟判断）
- **跨页**：5
- **学习点**：star / laugh / home · étoile / rire / maison

## 4. 做的顺序（建议）

1. **第 1 章 · 第一号画**：最短、最完整，验证"藏秘密 + 延迟判断"，也是全系列的宣言 → 先做成第一本完整的 Magic Book
2. **第 8 章 · 狐狸**：全系列的心脏，验证"真实多天驯服"这个最有原创性的魔法
3. **第 2 章 · 画羊**：验证"你来创造"，并把"你的羊"这条长线串起来
4. 其余按顺序补

每一章都走同样的流程：改编脚本（文字 + 分镜 + 魔法）→ 灰盒样书 → 出图 → 配音。
