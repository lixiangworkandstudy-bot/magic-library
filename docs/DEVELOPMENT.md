# 魔法书房 + 《纸月亮》立体书样片

## 入口：魔法书房（index.html）

- 圆形书房，六面墙 = 六个书区：1 新书上架 · 2 我正在读（开场正对）· 3 科学认知 · 4 童话经典 · 5 冒险 · 6 语言魔法
- 悬浮书：每面墙前常驻漂浮的书——低处（视线高度）= 当前级别可读；高处（回廊高度）= 更高级别（丝带 + 蜡封）
- 房间模式：拖动环顾；直接点任意一本书 → 飞到面前翻开
- 聚拢模式：点墙或墙脚铜牌 → 这面墙的书聚拢排好；左右滑动换墙；「回到书房」书再散开
- 书封：`js/covers.js` 设计系统（布纹 + 烫金边框 + 主题纹章 + 书名铭牌 + 级别星）；书有 `cover` 插画时插画铺底
- 视觉层次：墙面压暗 + 柔焦 + 降饱和（背景退后），书自发光（主角往前）；墙名只在魔法棒指到时出现；提示 7 秒后淡出
- 背景音乐：`js/music.js` 实时合成（音乐盒五声音阶即兴 + F-Dm-B♭-C 铺底 + 壁炉声），第一次点击后淡入，右上角 ♪ 开关，打开书时渐弱
- 第一次来：转身找发光的书（12 秒没找到它会飞过来）；以后来：壁炉前飘着"正在读"的书
- 升级：当前级别读完 3 本 → 升一级，解封的书从上层飞下来（规则在 `data/library.json` 的 `rules`）
- 读到立体书最后一页 → 记为"读过"，书架上挂金色书签

- **书的性格**（library.json 每本书的 `mood`）：魔法棒碰到时反应各不相同——害羞（先躲开再偷看）/ 瞌睡（打哈欠冒 z）/ 活泼（蹦跳转圈）/ 倔脾气（抖着冒烟）/ 好奇（凑近歪头）/ 骄傲（翻开封面亮金光）/ 摇摇晃晃；封印的书被碰到会拽拽丝带
- **隐形墨水**（library.json 的 `secrets`）：每面墙藏一句话，只有魔法棒的光照到才显形；显形时点一下 = 找到一个秘密（记在 profile.secrets）
- **猫头鹰图书管理员**（`js/owl.js`，台词在 library.json 的 `owl`）：点它 → 选想看的类型 → 按「能打开 > 等级够 > 没读过」挑书，书飞到面前停 10 秒；插画版放 `assets/library/owl.png`（可选 `owl-blink.png`），没有就用 SVG 雪鸮

| 改什么 | 改哪里 |
|---|---|
| 书单、书区、提示文案、升级规则 | `data/library.json` |
| 墙板 / 穹顶 / 地面 / 封面图 | 放进 `assets/library/`，文件名见 `library.json`（缺图自动用占位图） |
| 颜色、墙面压暗、蜡烛/光尘数量、书架排列、触碰反应 | `js/library.js` 顶部的 `THEME`、`SHELF`、`HOVER` |
| 音乐速度、和弦、音色 | `js/music.js` 顶部的 `BPM`、`CHORDS`、`PENTATONIC` |
| 书封样式、主题纹章 | `js/covers.js` |
| 孩子进度的存储 | `js/profile.js`（目前存在浏览器 localStorage） |

调试键（书房页）：**L** 切换级别，**R** 清空进度（都会刷新）。

## 正文：漂浮文字（`js/caption.js`）

- 正文面板默认收起，书占满画面；文字**漂浮在书的上方**（背后一团柔光雾，不画框），**一次一句**，说话人用小标签标出；书自动缩进文字和底栏之间
- 儿童阅读排版（`style.css`「儿童阅读字幕」）：英文 Andika（初学阅读字体）、中文霞鹜文楷（楷体 = 课本字形）；大字号；暖深靛蓝字色；**读到的词放大 1.4 倍 + 橙色 + 荧光笔底**，没读到的词略浅；月亮 / 外太空场景自动换浅色字
- 翻开书后自动朗读（浏览器 TTS），**字不动、读到哪个词亮哪个词**（有词边界事件就精确跟，没有就按字数估算）；一页读完，「下一页」箭头跳两下提示，不自动翻
- 点一个词 = 单独再读这个词；点字幕空白 = 重读这一句（朗读关掉时 = 下一句）；🔊 开关朗读；📜 全文 展开原来的正文面板
- 以后换真人/AI 配音：给 passage 加 audio + 词级时间戳即可

## 看书的角度和远近

- **角度刻度盘**：底栏里的小圆钮（里面的迷你指针 = 当前角度）→ 点开像折扇展开 → 拖指针连续调角度（每 5° 一声咔哒，靠近「📖 读字」88° / 「✨ 立体」34° 会吸附）；松手 4 秒或点别处自动收回。读字 = 镜头在正上方，纯文字的书也能读。
- **缩放**：底栏 ＋ / －、双指捏合、触控板捏合（含 Safari）、键盘 + / −、鼠标滚轮。

## 自适应布局（`app.js` 的 `LAYOUT` / `fitTextSize` / `fitBookAboveCaption`）

- 屏幕三层：上 = 漂浮文字，中 = 书，下 = 底栏
- 字号 = 舞台宽 × 2.8%（舞台宽 = min(屏宽, 屏高 × 1.5)，20–40px）；一行不超过书宽
- 书像照片「适应边框」一样装进文字和底栏之间：按书的包围盒（页面 + 立体纸片高度 `BOOK_BOUNDS`）投影量尺寸，填满 94%；竖屏时书贴近文字
- 屏幕尺寸、书的角度（刻度盘）、开合变化时自动重排；孩子自己的捏合缩放叠加在上面

## 翻页

- **拖着翻**：按住右页外侧（离书脊 35% 以外）往左拖，纸页跟手掀起；左页外侧往右拖 = 往回翻。松手时拖过 30% 或快速一甩就翻过去，否则纸页落回原处（`app.js` 里的 `PAGE_DRAG` 调这几个阈值）。
- **点一下翻**：轻点书页外侧 = 翻到下一页 / 上一页。书页上鼠标会变成「抓手」提示可以拖。
- 按钮 / 键盘翻页动画 2 秒（`book3d.js` 的 `TURN_MS`）。
- 取舍：在书页上拖 = 翻页，所以转视角要在书外面拖，或用角度刻度盘。

## book.json 里 scene 每个字段的意思（最常调的）

```
"anchor": [x, z]
    x：page 坐标下 0 = 书脊，1 = 外侧书边；spread 坐标下 0 = 左书边，1 = 右书边
    z：0 = 页面远端（靠近山），1 = 页面近端（靠近读者）
    → 背景放 0.15~0.25，中景 0.45~0.6，前景 0.8~0.9，纵深就出来了
"maxWidth" / "maxHeight"：纸片最大宽/高（单位 = 一页的宽/高），取两者中先碰到的那个
"side"：left / right，纸片粘在哪一页
"layer"：background / midground / foreground（影响立起来的先后顺序）
"coordinateSpace": "spread" + "crossGutter": true：横跨书脊的背景幕
```

## 页面底纹（ground）的规则

一张图 = **整个跨页**（1776×1000）。运行时左页取左半、右页取右半，所以 x=0.5 就是书脊。
印在纸上的只放"地面"：小路、水塘、草地；会立起来的东西都做成独立纸片。

## 会动的插图书（`js/pagebook.js`）—— Magic Book 的第二种形式

适合有文学性的原著（第一本：《小王子》第一册 `book.html?book=little-prince-1`）。书稿 `format: "illustrated"`：
- 书稿只给"内容流"（章节 / 段落 / 插图 / 魔法），**分页在浏览器里按真实字体排**，每个跨页是一张 canvas 贴到书页上（`book3d.js` 支持 canvas 资产）
